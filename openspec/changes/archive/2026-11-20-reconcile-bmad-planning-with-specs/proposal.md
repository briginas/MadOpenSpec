# Proposal

## Why

A BMAD planning document can still defer a capability after a direct OpenSpec change has established part of it. Planning from that document alone can duplicate accepted work and lose constraints.

## What Changes

- Compare affected current capability specs with the request and current BMAD requirements during ordinary planning.
- Route agreed requirement corrections to the document owner before decomposing affected stories.
- Install one shared planning rule through BMAD workflow customization during setup and update.

## Capabilities

### New Capabilities

### Modified Capabilities

- `agent-workflow` gains reconciliation during product planning, sprint change proposals and story decomposition.
- `toolchain-setup` installs and updates the four planning skill customizations while preserving project settings.

## Impact

Affects setup, update, the bundled planning instructions, usage documentation and verification against BMAD 6.12.4.
